## Executar Localmente

**Pré-requisitos:**  Node.js

1. Instalar as dependências:
   `npm install`
2. Definir a chave `GEMINI_API_KEY` em [.env.local](.env.local) com a sua chave da API da Gemini.
3. Executar o app:
   `npm run dev`
